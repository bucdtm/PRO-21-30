Lógica básica de decisión e iteración.

**FOR**:

```java
// Bucle estándar para contar
for (int i = 1; i <= 5; i++) {
    if (i % 2 == 0) {
        System.out.println(i + " es par");
    } else {
        System.out.println(i + " es impar");
    }
}
```

**WHILE**:

```java
int capacidadActual = 0;
final int CAPACIDAD_MAXIMA = 100;

// Se ejecuta MIENTRAS la condición sea verdadera
while (capacidadActual < CAPACIDAD_MAXIMA) {
    capacidadActual += 10; // Incremento
    System.out.println("Cargando sistema... Capacidad al " + capacidadActual + "%");
}
System.out.println("Sistema cargado.");
```

**DO-WHILE**:

```java
Scanner sc = new Scanner(System.in);
int numero;

do {
    System.out.print("Introduce un número positivo: ");
    while (!sc.hasNextInt()) { // Validación de tipo de dato
        System.out.println("Error: No es un número entero.");
        sc.next(); // Limpiar entrada incorrecta
        System.out.print("Introduce un número positivo: ");
    }
    numero = sc.nextInt();
    
    if (numero <= 0) {
        System.out.println("Error: El número debe ser mayor que 0.");
    }

} while (numero <= 0); // Repetir MIENTRAS el dato sea inválido

System.out.println("Dato válido registrado: " + numero);
```

|**Característica**|**Bucle while**|**Bucle do-while**|
|---|---|---|
|**Momento de Evaluación**|Al inicio (Pre-condición).|Al final (Post-condición).|
|**Ejecuciones Mínimas**|0 (Cero).|1 (Una).|
|**Caso de Uso Principal**|Iterar listas, leer archivos, lógica donde la condición puede ser falsa desde el principio.|Menús interactivos, validación de formularios, reintentos de conexión.|
|**Riesgo Común**|No entrar nunca al bucle si la variable de control no está inicializada correctamente.|Ejecutar una acción una vez incluso cuando no se debería (si no se controla la lógica interna).|
