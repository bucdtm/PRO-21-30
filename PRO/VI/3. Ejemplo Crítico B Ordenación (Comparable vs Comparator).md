**Concepto:** Diferenciar orden natural (interno) de orden por criterio (externo).

```java
// Implementación Comparable (Orden natural: por ID)
class Producto implements Comparable<Producto> {
    int id;
    double precio;

    public Producto(int id, double precio) { this.id = id; this.precio = precio; }

    @Override
    public int compareTo(Producto o) {
        return Integer.compare(this.id, o.id);
    }
}

// Uso en maquinaExpendedora
List<Producto> tienda = new ArrayList<>();
// ... añadir productos ...

Collections.sort(tienda); // Usa compareTo (Orden por ID)

// Comparator (Orden alternativo: por Precio)
Collections.sort(tienda, new Comparator<Producto>() {
    @Override
    public int compare(Producto p1, Producto p2) {
        return Double.compare(p1.precio, p2.precio);
    }
});
```
