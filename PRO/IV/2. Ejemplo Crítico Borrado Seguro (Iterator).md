**Problema:** Modificar la estructura mientras se recorre genera `ConcurrentModificationException`.

```java
Iterator<String> it = listaNombres.iterator();
while (it.hasNext()) {
    String nombre = it.next();
    if (nombre.equals("Carlos")) {
        // listaNombres.remove(nombre); // ERROR: Lanza excepción
        it.remove(); // CORRECTO: Borrado seguro a través del iterador
    }
}
```
