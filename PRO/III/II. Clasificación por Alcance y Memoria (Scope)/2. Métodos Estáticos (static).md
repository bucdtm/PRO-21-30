Pertenecen a la clase, no al objeto. No pueden acceder a `this` ni a atributos no estáticos. Son funciones utilitarias o globales.

```java
public static double calcularAreaCirculo(double radio) {
    return Math.PI * Math.pow(radio, 2);
    // Se llama: Clase.calcularAreaCirculo(5.0);
}
```

Static puede ser de cualquier tipo tanto void, boolean, String, etc.
