**Concepto:** Proteger el estado interno mediante `private` y lógica en los `setters`.

```java
public class Cuenta {
    private double saldo; // Oculto al exterior

    public void ingresar(double cantidad) {
        // Regla de negocio: No se permiten ingresos negativos
        if (cantidad > 0) {
            this.saldo += cantidad;
        }
    }
    // Getter de solo lectura
    public double getSaldo() { return this.saldo; }
}
```
