**Concepto:** Tratar distintos objetos como su clase base.

```java
List<Animal> zoologico = new ArrayList<>();
zoologico.add(new Perro());
zoologico.add(new Gato()); // Asumiendo que Gato existe

for (Animal a : zoologico) {
    a.hacerSonido(); // Enlace dinámico: ejecuta el método del hijo correspondiente
}
```
