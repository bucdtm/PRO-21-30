**Problema:** Validar formatos complejos sin encadenar múltiples `if`.

```java
String dni = "12345678Z";
// Regex: 8 dígitos seguidos de una letra mayúscula
String patronDNI = "[0-9]{8}[A-Z]";

if (dni.matches(patronDNI)) {
    System.out.println("Formato de DNI válido.");
} else {
    System.err.println("Error: Formato incorrecto.");
}
```

**Más Regex**:

## 1. Los Componentes Básicos (Átomos)

|**Símbolo**|**Significado**|**Ejemplo**|
|---|---|---|
|`.`|**Cualquier carácter** (excepto saltos de línea).|`h.la` → "hola", "hula", "h-la"|
|`\d`|Cualquier **dígito** (0-9).|`\d\d` → "25", "99"|
|`\w`|Cualquier **carácter alfanumérico** (letras, números, guion bajo).|`\w` → "a", "5", "_"|
|`\s`|Un **espacio en blanco** (espacio, tabulación).|`\d\s\d` → "1 2"|
|`[abc]`|**Conjunto:** Cualquier carácter dentro de los corchetes.|`[aeiou]` → busca cualquier vocal|
|`[^abc]`|**Negación:** Cualquier carácter que NO esté en el conjunto.|`[^0-9]` → busca cualquier cosa que no sea un número|

## 2. Cuantificadores (¿Cuántas veces?)

Los cuantificadores le dicen a la Regex cuántas veces debe repetirse el carácter anterior.

- `*`: Cero o más veces.
    
- `+`: Una o más veces.
    
- `?`: Cero o una vez (hace que el carácter sea opcional).
    
- `{n}`: Exactamente `n` veces.
    
- `{n,m}`: Entre `n` y `m` veces.
    

> **Ejemplo:** `\d{3}-\d{3}` buscaría un patrón como `123-456`.

## 3. Anclas (¿Dónde buscar?)

Las anclas no coinciden con caracteres, sino con **posiciones**.

- `^`: El inicio de una línea.
    
- `$`: El final de una línea.
    
- `\b`: Límite de palabra (evita encontrar una palabra dentro de otra).

## 4. Agrupamiento y Alternancia

- `( )`: **Grupos de captura.** Permiten agrupar partes de la expresión para aplicar cuantificadores o extraer esa parte específica después.
    
- `|`: **Operador OR.** Permite buscar una opción u otra.
    
    - _Ejemplo:_ `(gato|perro)` buscará cualquiera de las dos palabras.

## 5. Ejemplo Práctico: Validar un Email

Si quisiéramos crear una Regex para un correo electrónico básico, pensaríamos así:

1. **Nombre de usuario:** Letras o números (`[\w.-]+`)
    
2. **El arroba:** Literal (`@`)
    
3. **Dominio:** Letras (`[a-zA-Z-]+`)
    
4. **Punto:** Literal (se escapa con barra invertida porque el punto es especial: `\.`)
    
5. **Extensión:** Letras de 2 a 6 caracteres (`[a-zA-Z]{2,6}`)
    

**Resultado:** `^[\w.-]+@[a-zA-Z-]+\.[a-zA-Z]{2,6}$`
