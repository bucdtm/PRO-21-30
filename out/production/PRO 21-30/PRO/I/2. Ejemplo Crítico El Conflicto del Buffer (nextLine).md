**Problema:** `nextDouble()` lee el número pero deja el "Enter" (`\n`) en el buffer. El siguiente `nextLine()` lee ese vacío y salta.

```java
System.out.print("Introduce tu edad: ");
int edad = sc.nextInt();

// PUNTO DE INFLEXIÓN: Limpieza del buffer
sc.nextLine(); // Consumimos el \n residual explícitamente

System.out.print("Introduce tu nombre: ");
String nombre = sc.nextLine(); // Ahora la lectura es correcta
```
